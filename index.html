Criterio de Seleccion — 3 Tecnicas + Sint. STL: Se comparan Media global, Mediana global, Interpolacion Lineal y Serie Sintetica STL. El RMSE penaliza errores grandes al cuadrarlos. Complementado con MAE, R², Sesgo y Correlacion para determinar la tecnica mas efectiva por variable y gap.

Funciones y metodos aplicados en el codigo
Metrica / FuncionOperacion en PythonObjetivo
RMSE np.sqrt(mean_squared_error(y_true, y_pred)) Penaliza desviaciones mayores al cuadrado
MAE mean_absolute_error(y_true, y_pred) Error lineal medio — robusto a outliers
Interpolacion df.interpolate(method='time') Interpola usando el indice temporal
STL STL(serie, period=288).fit() Descompone tendencia + estacionalidad
Sesgo np.mean(y_pred - y_true) Error sistematico (sobre/subestimacion)
R² 1 - SS_res / SS_tot Variacion capturada por la tecnica
Correlacion np.corrcoef(y_true, y_pred)[0,1] Seguimiento del patron temporal
Analisis de residuos: residuo = imputado − real. Si los residuos tienen patron sistematico (siempre positivos = sobreestima, siempre negativos = subestima), el metodo tiene sesgo. Una distribucion simetrica centrada en 0 indica error aleatorio — estadisticamente ideal.
